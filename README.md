# SRVUSD eBus Energy Project

Version 1 of an independent student research website by Raymond Li.

## Publish with GitHub Pages
1. Create a new public GitHub repository (for example `srvusd-ebus-energy`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public site address after deployment.

## Important
- Do not add private or sensitive district data.
- Get permission before publishing interview quotes or identifying non-public contacts.
- Date and link factual claims because the district project may change during implementation.
- The site disclaimer should remain visible.
